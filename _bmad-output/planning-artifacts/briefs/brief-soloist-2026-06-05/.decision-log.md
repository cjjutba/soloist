- **Architecture:** Two portals (Freelancer cockpit ↔ Client experience), multi-tenant from day 1.

- **Notifications:** email + in-app + toast.
- **Domain:** subdomains on cjjutba.com.

- **MVP target:** ~2–4 week build.

## 2026-06-05 — Working mode + research

- **Working mode:** Fast path (batch gaps → draft with `[ASSUMPTION]` tags → iterate). User chose explicitly.
- **Competitive research returned** and saved to `addendum.md`. Key finding: the client-portal space is crowded/mature; a generic Soloist would be DOA. The honest, defensible differentiator is **dev-native** — auto-pulling the "what shipped" feed from GitHub/Vercel/Linear (+ AI plain-English summaries), which creative-tool-integrated incumbents won't chase. Premium onboarding = entry; live ship-feed = retention; dev-tool integration = moat. Pricing norm for solo tier is $9–24/mo flat.
- **Open decision surfaced to user:** whether to commit to the dev-native angle as the differentiator/roadmap (manual ship-feed still fine for the MVP). Awaiting answer before drafting.

### Fast-path batch answers (user-selected)

1. **Differentiator → "Dev-native in v1 itself."** Build the GitHub auto-feed (commits/PRs → client-readable ship updates) INTO the first version, not just the roadmap. Stronger day-1 moat; bigger scope.
2. **Primary user → "Me + other dev-freelancers now."** v1 designed for solo product-engineer freelancers (incl. CJ) serving startup/founder clients. Multi-tenant from day 1 supports this. Noted risk: designing for not-yet-real users before dogfood signal — captured as an open question.
3. **Pricing → "Defer entirely."** Business model is an explicit OPEN QUESTION in the brief; not scoped now. Market reference retained in addendum ($9–24/mo solo norm).

- **Scope consequence (logged honestly):** dev-native-in-v1 + multi-tenant-day-1 + build-for-others pushes the realistic MVP from ~2–4 weeks to **~4–8 weeks**. Stated plainly in the brief's Scope section.
- **Draft approach:** Fast path — full brief drafted now with `[ASSUMPTION]` tags on inferred items (success metrics, why-now specifics, dev-tool ordering, AI-summary-in-v1, demo-portal spec) for user correction in review.
