## 2026-06-05 — Fast-path draft v1 of both spines

Extracted PRD+brief into `.working/extracted-sources.md`. Authored DESIGN.md + EXPERIENCE.md inheriting shadcn/ui + Tailwind, specifying the brand-layer delta. Load-bearing author assumptions (all `[ASSUMPTION]`-tagged in the spines), awaiting CJ:

- **Per-Tenant accent mechanism:** `--tenant-accent` runtime CSS var; default Soloist Iris `#5B5BD6`; applies to Client surfaces + emails only, never the Cockpit. Client Portal re-scopes shadcn `primary` → tenant-accent.
- **Warm-neutral base:** Soloist Ink `#1C1B1F` + Warm Paper `#FBFAF8` overriding shadcn cool gray (premium-calm signal).
- **Type:** Fraunces serif `display` for premium moments (sparingly) + Geist Sans body (shadcn) + Geist Mono numeric. Serif = the "an agency made this" cue.
- **Fixed status vocabulary as design tokens:** ✅ Shipped (green) · 🚧 In Progress (amber) · 📦 Next (slate). Never per-Tenant.
- **Softer radii** than shadcn (sm6/md10/lg14/xl20) for premium-consumer read.
- **Curation = privacy boundary; no silent auto-publish** treated as a hard rule (PRD implied, not stated).
- **Contrast guard on the accent picker** treated as a hard accessibility rule (closes rubric FR-2 finding).
- **Onboarding default = pure reassurance, no Client input** (fastest path to the day-one "wow").
- **Cockpit keyboard primitives** (j/k/e/1-2-3/p/x, ⌘K) for fast curation; Client Portal touch-first zero-learning.
- **Cockpit @ `app.cjjutba.com`** assumed (PRD Open Q #8, unconfirmed).
